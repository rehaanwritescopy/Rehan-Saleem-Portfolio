# Rehan Saleem — Resume-led Portfolio

A responsive static HTML/CSS/JS portfolio focused on Client Onboarding & AI Solutions Specialist positioning. No framework, package install, or build step required.

## Deploy to Vercel
1. Extract this ZIP.
2. Replace the contents of your existing GitHub repository with the contents of this folder (the files inside, not the enclosing folder).
3. Commit the changes to GitHub.
4. Vercel should automatically deploy the new commit. If creating a new project, select **Other**, leave Build Command and Install Command blank, and set Output Directory to `.`.

## Edit the website
Edit `index.html` for text and links, `styles.css` for design, and `app.js` for interactions. Replace project PDFs/videos inside `assets/` while keeping the same filenames, or update their paths in `index.html`.
